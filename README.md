# Consulting

Роль: Ты — ведущий fullstack-разработчик и UI/UX дизайнер, работающий над созданием современного веб-приложения для личного бренда эксперта по поступлению.

Задача: Создать структуру, дизайн и базовый код для лендинга Рианы (Riana Admissions), используя React, Tailwind CSS и, возможно, Supabase (для простых динамических элементов, таких как отзывы или FAQ).

Основные принципы дизайна и стиля:

 * Эстетика: Минимализм, премиальность, вдохновленный лучшими SaaS-продуктами и образовательными платформами (как Lemon Squeezy или Stanford). Цветовая палитра: глубокий синий (navy), белый, золотой акцент (для CTA кнопок), серый (для текста).

 * Типографика: Современные шрифты без засечек (например, Geist, Inter или Poppins для заголовков, Roboto для основного текста).

 * Визуальное оформление: Используй высококачественные фотографии из предоставленных материалов, особенно те, где Риана выглядит профессионально и дружелюбно. Применяй эффект "Glassmorphism" (полупрозрачные карточки с размытием фона) для секций и Hero-блока.

 * Верстка: Адаптивный дизайн (mobile-first), плавные переходы и микро-анимации при наведении.

Структура и Содержимое Секций (Пошаговая инструкция для ИИ)

1. Навигация (Header)

 * Логотип: Слева текст "Riana Admissions" с небольшим графическим элементом (например, перо или стилизованная буква "R").

 * Навигационные ссылки: "Обо мне", "Услуги", "Результаты", "Отзывы", "FAQ".

 * Кнопка CTA: Справа, круглая кнопка "Записаться на консультацию" (белый текст, золотой фон, ссылка на Telegram/WhatsApp).

2. Главный блок (Hero Section)

 * Левая колонка:

   * Крупный заголовок с переносом строк: "Поступление в топовые вузы Китая с Riana Admissions. Ваш гид к успеху."

   * Подзаголовок: "Индивидуальное сопровождение, стратегия и подготовка документов. Откройте двери к образованию вашей мечты."

   * Двойной CTA:

     * Кнопка 1 (Gold): "Оставить заявку" (ведущая к форме записи/footer).

     * Кнопка 2 (Outline): "Узнать больше" (плавная прокрутка к секции "Обо мне").

   * Краткие достижения (иконки): "100+ студентов", "3.5M$ грантов", "Опыт 7 лет".

 * Правая колонка:

   * Крупное, стилизованное фото Рианы из предоставленных материалов (напр., img_0.png), обрамленное в мягкую рамку или на фоне с эффектом градиента.

3. Обо мне (About Section)

 * Заголовок: "Риана: Ваш персональный проводник в мир высшего образования".

 * Контент:

   * Короткий, убедительный текст, раскрывающий её экспертизу (на основе её информации). Подчеркнуть персонализированный подход, знание всех подводных камней и успех её студентов.

   * Включить одно-два качественных фото (напр., img_1.png или img_5.png) в профессиональной среде.

   * Обязательный элемент: Небольшой видеоролик или ссылка на него (иконка Play), если это возможно, где Риана говорит лично.

4. Услуги (Services Section)

 * Заголовок: "Как мы работаем: Программы сопровождения".

 * Дизайн: Сетка из 3-х карточек (Card Component, Glassmorphism).

   * Карточка 1 (Strategy): Иконка (карта/компас). Заголовок "Стратегическое планирование". Текст: "Выбор вузов, анализ профиля, создание дорожной карты поступления".

   * Карточка 2 (Documents): Иконка (документ/ручка). Заголовок "Сопровождение документов". Текст: "Работа над эссе, мотивационными письмами, рекомендациями, CV".

   * Карточка 3 (Full Support): Иконка (рукопожатие). Заголовок "Полное сопровождение". Текст: "От А до Я: от выбора вуза до зачисления и визовой поддержки".

 * Каждая карточка должна иметь свою кнопку "Детальнее" и выделение при наведении.

5. Результаты и кейсы (Results Section)

 * Заголовок: "Достижения студентов Riana Admissions".

 * Дизайн: Интерактивный слайдер или сетка из 4-х плиток.

 * Контент:

   * Плитка 1 (Число): "Принято в топ-20 вузов США".

   * Плитка 2 (Число): "Студентов получили стипендии/гранты".

   * Плитка 3 (Число): "Вуз + Специальность".

   * Плитка 4 (Число): "Вуз + Специальность".

 * Используй данные из скриншотов результатов (100+, 3.5M, Стэнфорд, Корнелл, UCL и т.д.), чтобы эти цифры выглядели убедительно.

6. Отзывы (Testimonials Section)

 * Заголовок: "Что говорят мои студенты".

 * Дизайн: Сетка из 3-х карточек с фото реальных студентов (используй изображения с результатами или просто аватары) и цитатами.

 * Контент: Текстовые отзывы, подчеркивающие эффективность работы Рианы, скорость и качество результата (например: "Благодаря Риане я получил оффер из Стэнфорда! Ее эссе-сервис — это магия...").

7. Вопросы и ответы (FAQ Section)

 * Заголовок: "Частые вопросы о поступлении".

 * Дизайн: Аккордеон (Accordion Component).

 * Контент: 5-6 основных вопросов с ответами, например:

   * Когда начинать подготовку?

   * Как выбрать вуз мечты?

   * Сколько стоит обучение в США/UK?

   * Нужен ли мне высокий SAT/IELTS/TOEFL?

   * В чем секрет успешного эссе?

8. Call to Action (Form Section)

 * Заголовок: "Готовы начать путь к зачислению? Запишитесь на первую консультацию".

 * Дизайн: Выделенная секция с контрастным фоном или Glassmorphism, содержащая форму.

 * Контент:

   * Поля: Имя, E-mail, Телефон/Telegram, Краткий вопрос/цель.

   * Кнопка CTA: "Отправить заявку".

   * Пометка: "Консультация бесплатная, места ограничены."

 * Напрямую использовать контактные данные из предоставленных фото (email, телефон) для быстрого доступа или автоматической ссылки.

9. Footer

 * Логотип Riana Admissions.

 * Краткие контакты (Email, Телефон).

 * Ссылки на социальные сети (Instagram, Telegram, LinkedIn).

 * Авторские права: © 2024 Riana Admissions. All rights reserved.

Технические требования (Advanced AI Prompts)

 * React Component Library: Использовать качественные готовые компоненты (например, из ShadcnUI или Headless UI) для элементов UI, чтобы они выглядели профессионально (кнопки, аккордеоны, модальные окна).

 * Tailwind Configuration: Настроить файл tailwind.config.js с использованием кастомных цветов (глубокий синий, золотой акцент) и шрифтов.

 * Dynamic Content: Подключить простые динамические элементы, такие как отзывы или FAQ, через Supabase, чтобы Риана могла редактировать их в будущем без переписывания кода.

 * Animation: Использовать библиотеку типа Framer Motion для плавного появления элементов при прокрутке (scroll animations).

 * Performance: Оптимизация изображений для быстрой загрузки.

 * SEO: Добавление мета-тегов и заголовков для поисковой оптимизации (Riana Admissions, консультации по поступлению, эссе в США, обучение за границей).

Дополнительные инструкции для ИИ-движка:

 * Сгенерировать код для полного лендинга, разделенный на компоненты React (Header.jsx, Hero.jsx, About.jsx, Services.jsx, Results.jsx, Testimonials.jsx, FAQ.jsx, Form.jsx, Footer.jsx).

 * Использовать реальные данные и фотографии из прикрепленных файлов, где это возможно, и предоставить placeholder-данные, где информации недостаточно, но следовать тону бренда.

 * Сайт должен быть полностью адаптивным, с безупречным отображением на экранах мобильных телефонов и десктопов.

 * Использовать переменные CSS для цветов, чтобы легко менять палитру в будущем.

 * Убедиться, что все CTA кнопки ведут к одной цели — сбору лидов или контактов.
